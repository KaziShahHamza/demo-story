# Demo Story Multi-Agent Rules

1. Never commit directly to `main`; use `git worktree` and feature branches.
2. Every episode in `episodes/` must include `episodeNumber`, `title`, `releaseDate`, and `summary` in YAML frontmatter.
3. Update `CHARACTERS.md`, `TIMELINE.md`, and `README.md` with each episode PR.
4. Run `npm run lint`, `npm test`, and `npm run build` before opening or updating any PR.
