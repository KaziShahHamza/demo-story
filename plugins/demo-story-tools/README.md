# `demo-story-tools` Plugin

A shareable Antigravity plugin bundle for `demo-story` containing:
- **Agents:** `episode-author`, `lore-reviewer`, `code-reviewer`
- **Rules:** `rules/AGENTS.md` (multi-agent workflow & verification rules)
- **Workspace Skills:** Mirrors `.agents/skills/` (`episode-writer`, `lore-continuity`, `git-worktree-flow`)
