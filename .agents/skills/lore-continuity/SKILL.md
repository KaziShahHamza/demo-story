# Lore Continuity Skill

Use this skill whenever an episode is drafted or reviewed.

## 1. Shared Files to Update
Every episode PR should update:
1. `CHARACTERS.md` — Add or update character traits, first appearance, and key items introduced in the episode.
2. `TIMELINE.md` — Fill in the episode's row with Story Date / Era and Key Event.
3. `README.md` — Update the Episode Schedule table status from `Planned` to `Released` (or `Drafted`).

## 2. Continuity Checklist
- Character names, house affiliations, and magical items match prior episodes.
- Dates in `TIMELINE.md` progress chronologically (1981 → Summer 1991 → School Year 1991–1992).
- No spoilers from future episodes leak into earlier episodes' summaries.
