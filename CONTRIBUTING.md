# Contributing to `demo-story`

Thank you for contributing to **demo-story**! Please follow the rules in [AGENTS.md](./AGENTS.md):

1. **Fork or Worktree:** Never commit directly to `main`. Create a feature branch (`feat/epXX-...`, `fix/...`, `chore/...`).
2. **Commit Messages:** Prefix with `[agent-name]` or `[contributor]` and conventional commit style:
   `[copilot] fix(ep01): polish opening paragraph`
3. **Pull Requests:** Link the GitHub Issue (`Closes #1`) and ensure CI (`lint`, `test`, `build`) passes.
4. **Reviews:** Every PR must be reviewed before merging.
